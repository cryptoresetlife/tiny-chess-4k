A chess engine in 4 KB of Python: mailbox board, PVS with a transposition table, null-move and late-move reductions, quiescence search, and piece-square tables rebuilt at every root (passed pawns, open files, king proximity), searching a fixed number of nodes a move, plus a small per-scenario table of variant seeds.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
